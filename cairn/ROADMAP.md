# ChemTrack 路线图

**当前重点**：核心系统已全量实现（M1–M7）；下一阶段是上线前的数据治理与试点准备。

## 里程碑

- [x] M1 基础：schema、认证、授权中心、哈希链审计、Docker
- [x] M2 库存核心：列表、调量对话框、详情页、Dashboard
- [x] M3 旧数据导入：流水线 + dry-run 闸门 + 修正工作台（479 容器已导入）
- [x] M4 流转：入库向导、出库、转移申请、跨实验室查找、QR 标签
- [x] M5 安全：告警引擎、相容性矩阵、GHS 编辑器、SDS 库、worker
- [x] M6 盘点与管理：盘点会话、用户/权限、实验室/位置、审计查看器
- [x] M7 报表与收尾：四个标准报表、导出、定时邮件、CI、README
- [ ] 数据治理：Import fixup 清零（221 个待指派保管人、1 个歧义单位、9 个残缺位置、CAS 补录）
- [ ] 真实人员名册建号与 lab membership 配置
- [ ] 内网服务器 Docker 部署 + 备份计划（pgdata + files 卷）
- [ ] 试点实验室上线（切换日用最新 xlsx 重导 + 旧系统冻结）
- [ ] 后续增强：机构 SSO（OIDC）、管控品 TOTP 2FA、PubChem CAS 辅助补录

## 开放问题

1. 相容性三态规则表需 EHS 认可（当前为种子数据，来源标记 LOCAL_EHS_RULE）。
2. 管控品判定标准：按许可证类别还是物质清单标记 `isControlled`？（驱动 restricted 模式与 witness 规则）
3. 导入的旧位置目前统一为顶层 OTHER 类型，相容性页选择器被 ~100 个旧位置码占满——需归类为柜/层或给选择器加分组/搜索。
4. 报表中的"spend/成本"维度：schema 暂无成本字段，是否需要在采购环节补充？
